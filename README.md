# DeltaDevelop — استودیو توسعه نرم‌افزار

دامنه: https://deltadevelop.ir

پروژه مستقل معرفی خدمات طراحی و توسعه نرم‌افزار، با پنل Django و API مدیریتی امن برای ربات مشترک چندسایتی. در فاز نخست **پرداخت و فروش فعال نیست**؛ درخواست‌های پروژه برای بررسی مدیر ثبت می‌شوند.

توجه: هیچ نمونه‌کار، مشتری، مجوز یا فروش ساختگی در سایت نمایش داده نمی‌شود. اطلاعات کسب‌وکار، تماس و شرایط خدمات باید پیش از درخواست اینماد توسط مالک تکمیل و راستی‌آزمایی شود.

## راه‌اندازی توسعه

پس از تکمیل ساختار پروژه، دستورهای نصب و راه‌اندازی در همین فایل اضافه می‌شوند.
